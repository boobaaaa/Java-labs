# Задание 1

## Задача 1.1: Обобщенная коробка

### Текст задачи
Создайте сущность Коробка, которая обладает следующими характеристиками:
- Может хранить один произвольный объект в один момент времени
- Объект можно получить и разместить на хранение в любой момент времени
- Если объект забирают из коробки – ссылку на этот объект необходимо обнулить
- Если объект кладут в коробку, но она не пуста – необходимо выкинуть исключение
- Имеет метод проверки на заполненность
- Методы класса должны работать с тем типом данных, который был указан во время создания объекта

Создайте Коробку которая может хранить целочисленное значение, разместите туда число 3.
Передайте Коробку в какой-либо метод, извлеките значение, и выведите его на экран

### Алгоритм решения
1. Создан обобщенный класс `Box<T>` с типовым параметром `T`
2. Реализованы методы:
   - `put(T newValue)` - размещение объекта с проверкой на пустоту коробки
   - `get()` - получение объекта без извлечения
   - `take()` - извлечение объекта с обнулением ссылки
   - `isEmpty()` - проверка на пустоту
   - `isFull()` - проверка на заполненность
3. Добавлены конструкторы: по умолчанию и с начальным значением
4. Переопределен метод `toString()` для строкового представления
5. В демонстрации создана коробка для целых чисел, размещено число 3 и извлечено

## Задача 1.2: Хранилище без null

### Текст задачи
Создайте сущность Хранилище, которая обладает следующими характеристиками:
- Может хранить один произвольный объект в один момент времени
- Хранилище неизменяемо
- Объект кладется в Хранилище при его создании. В качестве объекта может быть сохранено также и значение null
- Хранилище может вернуть ссылку на Объект
- Если вместо объекта хранится null, необходимо вернуть какое-либо альтернативное значение
- Метод получения значения должен работать с тем типом данных, который был указан во время создания объекта

Выполните следующие задания:
- Создайте Хранилище чисел, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число 0
- Создайте Хранилище чисел, положите туда значение 99. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число -1
- Создайте Хранилище строк, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка "default"
- Создайте Хранилище строк, положите туда значение "hello". Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка "default"

### Алгоритм решения
1. Создан обобщенный класс `Storage<T>` с двумя полями: значение и альтернатива
2. Класс сделан неизменяемым (поля `final`)
3. Реализован конструктор, принимающий значение и альтернативу
4. Метод `get()` возвращает значение, если оно не `null`, иначе возвращает альтернативу
5. Переопределен метод `toString()` для информативного вывода
6. Созданы методы `processNumberStorage()` и `processStringStorage()` для демонстрации работы с хранилищами разных типов
7. Продемонстрированы все требуемые сценарии

## Задача 3.1: Функция (map)

### Текст задачи
Разработайте такой метод, который будет принимать список значений типа T, и объект имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка, и вернуть новый список значений типа P, при этом типы T и P могут совпадать, а могут не совпадать.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", а получите список чисел, где каждое число соответствует длине каждой строки
2. Передайте в метод список со значениями: 1,-3,7, а получите список в котором все отрицательные числа стали положительными, а положительные остались без изменений
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только максимальные значения каждого из исходных массивов

### Алгоритм решения
1. Создан класс `FunctionalUtils` со статическим обобщенным методом `map()`
2. Метод принимает `List<T>` и `Function<T, R>` (функциональный интерфейс из Java)
3. Реализован проход по списку с применением функции к каждому элементу и созданием нового списка результатов
4. Созданы конкретные реализации `Function`:
   - `StringLengthFunction` - преобразует строку в её длину
   - `AbsoluteValueFunction` - возвращает абсолютное значение числа
   - `MaxArrayFunction` - находит максимальный элемент в массиве целых чисел
5. Продемонстрирована работа метода с разными типами данных

## Задача 3.2: Фильтр

### Текст задачи
Разработайте такой метод, который будет принимать список значений типа T и объект имеющий единственный метод test (принимает T и возвращает boolean). Верните новый список типа T, из которого удалены все значения не прошедшие проверку условием.

Используйте разработанный метод следующим образом:

## Задача 3.3: Сокращение (reduce)

### Текст задачи
Разработайте такой метод, который будет принимать список значений типа T и способ с помощью которого список значений можно свести к одному значению типа T, которое и возвращается из метода.

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и сформируйте одну большую строку, которая состоит из всех строк исходного списка
2. Передайте в метод список со значениями: 1,-3,7, и верните сумму всех значений исходного списка
3. Имеется список, состоящий из списков целых чисел, получите общее количество элементов во всех списках

Далее необходимо изменить разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.

### Алгоритм решения
1. Реализовано две версии метода `reduce()` в классе `FunctionalUtils`:
   - Первая версия: `reduce(List<T>, BinaryOperator<T>)` - может вернуть `null` для пустого списка
   - Вторая версия: `reduce(List<T>, T identity, BinaryOperator<T>)` - безопасная версия с начальным значением (identity)
2. Методы используют `BinaryOperator<T>` для последовательного объединения элементов
3. Созданы конкретные реализации `BinaryOperator`:
   - `StringConcatenator` - конкатенирует строки
   - `IntegerSum` - суммирует числа
4. Для задачи 3.3 использована комбинация `map()` и `reduce()`: сначала получены длины списков через `map()`, затем они просуммированы через `reduce()`
5. Продемонстрирована разница между безопасной и небезопасной версиями метода

## Задача 3.4: Коллекционирование

### Текст задачи
Разработайте такой метод, который будет возвращать коллекцию типа P со значениями типа T. Данный метод будет принимать:
1. Список исходных значений
2. Способ создания результирующей коллекции
3. Способ передачи значений исходного списка в результирующую коллекцию

Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: 1,-3,7, и верните их разбитыми на два подсписка, в одном из которых будут только положительные числа, а в другом только отрицательные
2. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", "qw" и верните их разбитыми на подсписки таким образом, чтобы в любом подсписке были строки только одинаковой длины
3. Передайте в метод список со значениями: "qwerty", "asdfg", "qwerty", "qw" и верните набор такого вида, который не может содержать одинаковые объекты

### Алгоритм решения
1. Создан обобщенный метод `collect()` в классе `FunctionalUtils` с тремя параметрами:
   - `List<T>` - исходные данные
   - `Supplier<P>` - поставщик для создания результирующей коллекции
   - `BiConsumer<P, T>` - потребитель для добавления элементов в коллекцию
2. Реализована логика создания коллекции и заполнения её элементами
3. Созданы конкретные реализации `BiConsumer`:
   - `NumberClassifier` - классифицирует числа на положительные и отрицательные, сохраняя в `Map<String, List<Integer>>`
   - `StringLengthGrouper` - группирует строки по длине, сохраняя в `Map<Integer, List<String>>`
4. Для получения уникальных строк использован `HashSet` с методом `add` как `BiConsumer`
5. Показаны примеры группировки, классификации и получения уникальных элементов
