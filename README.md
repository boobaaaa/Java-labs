# Задание 1: Квадрат и Сторона Квадрата

### Текст задачи 
Создайте сущность Квадрат. Квадрат описывается следующими характеристиками:
- Имеет Точку, отмечающую левый верхний угол
- Имеет длину стороны
- Создается путем указания точки левого верхнего угла и размера стороны
- Создается путем указания координат x и y левого верхнего угла и размера стороны
- Может быть приведен к строке вида "Квадрат в точке T со стороной N"
- Может возвращать новую Ломаную, точки которой соответствуют точкам углов текущего квадрата

Необходимо выполнить следующие задачи:
- Создайте Квадрат в точке {5;3} со стороной 23
- Присвойте в ссылку типа Ломаная результат вызова метода получения Ломаной у ранее созданного квадрата
- Выведите на экран общую длину полученной Ломаной
- Сдвиньте последнюю Точку Ломаной в позицию {15,25}
- Снова выведите на экран длину Ломаной

Измените сущность Квадрат. Гарантируйте, что Квадрату невозможно задать отрицательное значение длины стороны. При попытке задать сторону равной нулю или менее, выбрасывается ошибка с соответствующим текстом. Контроль должен осуществляться как во время создания объекта, так и позднее, в случае если будет необходимо менять размеры Квадрата. Необходимо предоставить возможность изменения длины стороны Квадрата и возможность узнать размер стороны.

### Алгоритм решения
1. Создаем класс `Square` с полями: `Point topLeft` и `double side`
2. Реализуем два конструктора:
   - `Square(Point topLeft, double side)` - через объект Point
   - `Square(double x, double y, double side)` - через координаты
3. Добавляем проверку на положительное значение стороны в сеттере и конструкторах
4. Реализуем метод `getPolygonalChain()`, который создает ломаную из 4 точек углов квадрата
5. Добавляем методы `getSide()` и `setSide(double side)` для доступа к стороне
6. Реализуем метод `toString()` в требуемом формате
7. В демонстрации создаем квадрат, получаем ломаную, вычисляем ее длину, изменяем точку и пересчитываем длину

# Задание 2: Бинарное дерево

### Текст задачи 
Необходимо реализовать структуру данных, представляющую собой простейшее бинарное дерево. Для формирования данного дерева будет использоваться сущность Узел.

Состояние сущности описывается следующими характеристиками:
- Значение, целое число
- Родитель, Узел
- Левый потомок, Узел
- Правый потомок, Узел

Инициализация сущности выполняется без аргументов.

Поведение сущности описывают следующие действия:
- Добавление значения
- Удаление значения
- Проверка на существование значения
- Приведение к строке

После реализации сущности, создайте её экземпляр и добавьте в него числа: 3 5 4 7 1 2. Выведите на экран текстовое представление узла.

### Алгоритм решения
1. Создаем класс `Node` с полями: `Integer value`, `Node parent`, `Node left`, `Node right`
2. Реализуем конструктор без параметров
3. Реализуем метод `addValue(int newValue)`:
   - Если значение не задано - устанавливаем его
   - Если задано: большее значение идет в правый потомок, меньшее или равное - в левый
   - Если потомок отсутствует - создаем его
4. Реализуем метод `contains(int searchValue)` для поиска значения
5. Реализуем метод `removeValue(int removeValue)` с обработкой трех случаев:
   - Удаляемый узел - лист
   - Узел имеет одного потомка
   - Узел имеет двух потомков
6. Реализуем метод `toString()` с левосторонним обходом в глубину
7. В демонстрации создаем дерево и добавляем указанные числа

# Задание 3: Замкнутая ломаная

### Текст задачи 
Создайте такой подвид сущности Ломаная, который будет представлять собой замкнутую ломанную линию, то есть последовательность точек, начинающихся и заканчивающихся на одной и той же точке. Данная сущность во всех отношениях совпадает с обычной Ломаной, кроме расчета длины.

### Алгоритм решения
1. Создаем класс `ClosedPolygonalChain`, наследуемый от `PolygonalChain`

   - Вычисляем длину обычной ломаной (сумма расстояний между последовательными точками)
   - Добавляем расстояние от последней точки к первой
3. Переопределяем метод `toString()` для отличия от обычной ломаной
4. Также реализуем метод `getPolygonalChain()` для совместимости с интерфейсом

# Задание 4: Фигуры

### Текст задачи 
Необходимо продумать структуру и организацию следующих геометрических фигур:

3. Прямоугольник. Задается точкой координат левого верхнего угла и двумя сторонами.
4. Треугольник. Задается тремя точками координат.

Для каждой фигуры обязательно должна быть возможность рассчитать её площадь.

2. Реализуем классы, соответствующие каждой фигуре:
   - `Circle`: поля `Point center`, `double radius`
   - `Square`: уже реализован в задании 1 (дополняем интерфейсом)
   - `Rectangle`: поля `Point topLeft`, `double width`, `double height`
   - `Triangle`: поля `Point a`, `Point b`, `Point c`
3. Для каждой фигуры реализуем:
   - Конструкторы с разными параметрами
   - Метод `getArea()` с соответствующей формулой
   - Метод `toString()` для строкового представления
