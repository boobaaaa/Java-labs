# Задание 1
## Задача 1: Имена
### Текст задачи
Создайте сущность `Name`, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду в формате `Фамилия Имя Отчество` (например, “Иванов Иван Иванович”). Если какой-либо параметр не задан, он не учитывается при формировании строки.  
Необходимо создать следующие имена:  
- Клеопатра  
- Пушкин Александр Сергеевич  
- Маяковский Владимир  

### Алгоритм решения
1. Создан класс `Name` с полями `lastName`, `firstName` и `patronymic`.  
2. Реализованы три конструктора: только имя, имя с фамилией, полное имя.  
3. Переопределён метод `toString` для красивого вывода, игнорируя отсутствующие параметры.  
4. Созданы объекты для указанных имён и выведены на экран.

# Задание 2
## Задача 1: Человек с именем
### Текст задачи
Объедините сущности `Person` и `Name` так, чтобы имя человека задавалось объектом `Name`, а не строкой. Необходимо получить:  
- Человека с именем Клеопатра и ростом 152  
- Человека с именем Пушкин Александр Сергеевич и ростом 167  
- Человека с именем Маяковский Владимир и ростом 189  

### Алгоритм решения
1. Создан класс `Person` с полями `Name name` и `int height`.  
2. Конструкторы позволяют создавать человека с заданным именем и ростом.  
3. Переопределён метод `toString` для вывода имени и роста.  
4. Созданы объекты людей с использованием ранее созданных объектов `Name`.

## Задача 2: Человек с родителем
### Текст задачи
Изменить сущность `Person`, добавив возможность задавать отца (`Person father`). При выводе на экран:  
- Если фамилия отсутствует, но есть отец с фамилией, использовать фамилию отца.  
- Если отчество отсутствует, но есть отец с именем, создавать отчество как имя отца + "ович".  

Необходимо создать:  
1. Чудова Иван, Чудова Петр, Борис  
2. Сделать Ивана отцом Петра, Петра — отцом Бориса  
3. Вывести всех на экран  

### Алгоритм решения
1. Класс `Person` получил поле `Person father` и метод `setFather`.  
2. В `setFather` реализована логика наследования фамилии и создания отчества.  
3. Созданы объекты людей с заданием отцов и выведены на экран.  

# Задание 3
## Задача 1: Ломаная
### Текст задачи
Создать сущность `Polyline`, представляющую ломаную линию через массив точек `Point`. Ломаная должна выводиться в формате: `Линия [T1, T2, ..., TN]`.  
Необходимо:  
- Создать первую Ломаную через точки {1;5}, {2;8}, {5;3}  
- Создать вторую Ломаную с совпадающими первой и последней точкой, и промежуточными точками {2;-5}, {4;-8}  
- Сдвинуть начало первой ломаной, чтобы одновременно сдвинулось начало второй  

### Алгоритм решения
1. Создан класс `Point` с координатами и методами `distanceTo` и `shift`.  
2. Класс `Polyline` хранит список точек и реализует `toString`.  
3. Созданы две ломаные линии и выполнен сдвиг начала первой линии, что также влияет на вторую.

# Задание 5
## Задача 1: Длина Ломаной
### Текст задачи
Изменить сущность `Polyline` для:  
- Возможности добавления новых точек к уже существующим  
- Вычисления общей длины ломаной  

Необходимо:  
1. Создать ломаную через точки {1;5}, {2;8}, {5;3}  
2. Вывести её длину  
3. Добавить точки {5;15}, {8;10} и снова вывести длину  

### Алгоритм решения
1. В классе `Polyline` добавлен метод `addPoints` для добавления новых точек.  
2. Метод `length` вычисляет длину ломаной суммой расстояний между последовательными точками.  
3. Создан объект ломаной, рассчитана длина, добавлены новые точки и длина пересчитана.
