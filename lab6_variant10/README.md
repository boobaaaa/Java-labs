## **Общая идея**

В лабораторной работе реализованы **пользовательские аннотации** и обработчики, которые позволяют:

* считывать их через **рефлексию**
* выполнять на основе этих аннотаций различные действия (например: вызов методов, построение строки, чтение параметров)

# **Аннотация 1: `@Invoke`**

## **Текст задачи**

Создать аннотацию `@Invoke`, которая применяется к методу.
Программа должна автоматически находить такие методы и вызывать их.

---

## **Алгоритм решения**

1. **Создана аннотация `@Invoke`**

   * применяется только к методам (`ElementType.METHOD`)
   * доступна во время выполнения (`RetentionPolicy.RUNTIME`)

   ```java
   @Target(ElementType.METHOD)
   @Retention(RetentionPolicy.RUNTIME)
   public @interface Invoke {}
   ```

2. **Создан класс `InvokeDemo`**

   * содержит метод `inc()`, помеченный `@Invoke`
   * содержит обычный метод `sayHello()`, который не должен вызываться автоматически

3. **Создан обработчик `InvokeProcessor`**

   * перебирает все методы класса
   * ищет методы с аннотацией `@Invoke`
   * проверяет что у них нет параметров
   * вызывает их через reflection (`invoke()`)

   ```java
   public static void invokeAll(Object target)
   ```

---

## **Демонстрация**

При запуске пункта меню `@Invoke` программа:

* создаёт объект `InvokeDemo`
* выводит значение счётчика
* автоматически вызывает метод `inc()`
* снова выводит значение счётчика

# **Аннотация 2: `@Default`**

## **Текст задачи**

Создать аннотацию `@Default`, которая может применяться:

* к классу
* к полю

Аннотация хранит **тип по умолчанию**.

---

## **Алгоритм решения**

1. **Создана аннотация `@Default`**

   * принимает параметр `Class<?> value`

   ```java
   public @interface Default {
       Class<?> value();
   }
   ```

2. **Создан класс `DefaultDemo`**

   * на класс установлено `@Default(String.class)`
   * на поле установлено `@Default(Integer.class)`

3. **Создан обработчик `DefaultProcessor`**

   * умеет читать аннотацию с класса и с поля

   Методы:

   ```java
   readDefaultFromClass(Class<?> clazz)
   readDefaultFromField(Field field)
   ```

---

## **Демонстрация**

Программа выводит в консоль:

* какой тип указан в аннотации класса
* какой тип указан в аннотации поля

# **Аннотация 3: `@ToString`**

## **Текст задачи**

Создать аннотацию `@ToString`, чтобы управлять тем, какие поля должны попадать в строковое представление объекта.

### Требование:

* поля с режимом `NO` не показывать

---

## **Алгоритм решения**

1. **Создана аннотация `@ToString`**

   * может применяться к классу и полю
   * имеет параметр `Mode` со значениями `YES / NO`

   ```java
   public @interface ToString {
       enum Mode { YES, NO }
       Mode value() default Mode.YES;
   }
   ```

2. **Создан класс `Person`**

   * поля: `name`, `password`, `age`
   * поле `password` помечено как `@ToString(NO)` чтобы скрывать его

3. **Создан обработчик `ToStringProcessor`**

   * перебирает поля класса
   * если поле помечено `NO` → пропускает
   * остальные поля добавляет в строку формата:

   ```
   Person{field=value, field=value}
   ```

   Метод:

   ```java
   public static String build(Object obj)
   ```

---

## **Демонстрация**

Пользователь вводит данные человека:

* имя
* пароль
* возраст

Программа печатает строку объекта, при этом **пароль не выводится**.
